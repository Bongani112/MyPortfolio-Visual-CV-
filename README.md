# MyPortfolio-Visual-CV-
A dynamic, interactive, and fully responsive personal Virtual CV built to showcase software development projects, technical skills, and academic background. Includes an AI-assisted navigation chatbot and dynamic UI elements.

Live Demo:

Check out the live interactive website here:  
[View Live Virtual CV]: (https://my-portfolio-visual-cv.vercel.app/)

Features & Functionalities

Interactive AI Assistant: Floating chatbot widget that helps visitors quickly search for projects, navigate to specific sections, or download the CV using natural text queries.
Dynamic Typing Effect: Auto-typing header text that introduces key technical roles and qualifications dynamically upon page load.
Dark / Light Mode Toggle: Smooth client-side theme switcher utilizing CSS custom variables and `localStorage` to preserve user preference.
Responsive Layout: Mobile-first architecture using CSS Grid and Flexbox, featuring a collapsible mobile navigation drawer.
Project Showcase: Display cards highlighting key software engineering, full-stack, and networking projects with direct links to GitHub source code.
Direct CV Download: One-click download button for an updated offline PDF curriculum vitae.

Built With Visual Studio: 

HTML5: Semantic web markup and structured layout.
CSS3: Custom styles, CSS variables, keyframe animations, and media queries.
JavaScript (Vanilla ES6+): DOM manipulation, AI logic engine, dark mode persistence, and typing effects.
FontAwesome: Scalable iconography.
GitHub Pages: Production hosting and deployment.
